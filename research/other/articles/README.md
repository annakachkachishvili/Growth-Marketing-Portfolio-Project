# Articles — collected long-form material, by author

Long-form articles (blog posts, newsletters, guides) are deeper than the experts' short-form posts and are the best raw material for the playbook. This folder mirrors the per-author structure of `/linkedin-posts` and `/youtube-transcripts`: **one folder per author**, with the captured material inside, ready to use in the next step.

Each file is a **capture**: metadata (title, author, URL, date), a full structured summary of the substance (frameworks, steps, data), short quoted-and-attributed key passages, and a playbook takeaway. (I capture substance + key passages rather than republishing full copyrighted articles verbatim — more useful for the playbook and the compliant way to do it.)
